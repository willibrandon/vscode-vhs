---
title: Getting started
description: Open a tape and start editing.
---

Install the extension, then open any `.tape` file. Language support starts automatically.

```vhs
Output demo.gif
Set Shell bash
Set Theme "Charmbracelet"

Type "echo hello"
Enter
Sleep 1s
```

Install [VHS](https://github.com/charmbracelet/vhs) plus `ffmpeg` and `ttyd` to run tapes.
