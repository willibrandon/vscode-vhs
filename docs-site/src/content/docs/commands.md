---
title: Commands
description: Commands available from the Command Palette.
---

- **VHS: Run Tape** runs the active tape.
- **VHS: Run and Preview** runs it and opens output.
- **VHS: Open Preview** opens existing output.
- **VHS: Stop Tape** stops active runs.
- **VHS: Validate with Installed VHS** runs `vhs validate`.
- **VHS: Restart Language Server** restarts language support.
- **VHS: Open Documentation** opens this site.
- **VHS: Show Language Server Output** opens language logs.
- **VHS: Show Run Output** opens run logs.
