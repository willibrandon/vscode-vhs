---
title: VHS for Visual Studio Code
description: Edit VHS tape files in VS Code.
---

Highlight, complete, check, navigate, format, run, and preview VHS tapes.

```vhs
Output demo.gif
Set Shell "bash"
Set TypingSpeed 40ms

Type "echo Hello from VHS"
Enter
Sleep 1s
```

![VHS completion in Visual Studio Code](../../assets/completion.png)

The extension works on desktop, remote hosts, and vscode.dev. VHS is optional for editing and
required only to run or validate tapes.

[Install the extension](./getting-started/) or read about [editing](./editing/).
