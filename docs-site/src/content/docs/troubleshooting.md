---
title: Troubleshooting
description: Fix common setup problems.
---

If a `.tape` file has no highlighting, check the language mode in the status bar and choose **VHS**.

If a run fails, open **VHS Run**. Check that `vhs`, `ffmpeg`, and `ttyd` are installed and available
to VS Code. Set `vhs.executablePath` when VHS is elsewhere.

Use **VHS: Restart Language Server** if editing features stop. Language details are in **VHS
Language Server** output.
